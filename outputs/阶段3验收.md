# 阶段 3：拍照识别

改动：src/components/OcrImport.tsx、src/services/ocr.ts、src/domain/ocr.ts 及测试、src/main.tsx、src/i18n/zh-CN.ts、src/style.css、scripts/prepare-ocr.mjs、public/ocr/chi_sim.traineddata.gz 及来源许可证、vite.config.ts、依赖与忽略规则。

已实现：拍照/相册、四边裁剪、长边 2000px 缩放、灰度对比度、Web Worker、本地 fast 中文模型、进度与取消、OcrProvider 接口、多列位置排序、汉字后处理、去重、勾选编辑删除合并拆分、确认后加入输入或保存词单；识别不会直接入库。

验证：19 项测试通过，build 通过，Mac npm run dev 及预准备资源脚本成功。浏览器真实加载本地 Worker 和模型识别双列画布，按列返回四个词，3 个正确、1 个错字（花朵误识别），确认页必需。所有 OCR 运行资源均在 /Dangdang/ocr/，预缓存包含这些资源，模型原始 2469156 字节，各单文件小于 25MiB。

运行：npm ci → npm run dev；npm test；npm run build。首次访问需联网下载应用自带资源，后续离线验证在阶段 6。

已知问题：未使用孩子真实课本，倾斜、阴影、细小字体、正文混排会影响准确率；自动多列排序是启发式，必须在确认页核对。取消可立即关闭界面，若发生在 Worker 初始化期间，会在初始化返回后销毁 Worker。相机授权由系统文件选择器控制，拒绝时可选相册或键盘扫描文本。
