# iPad / iPhone 真机验收清单

网址：https://sunriselifegarbo.github.io/Dangdang/

每个项目请在 Safari 和「添加到主屏幕」两种模式各做一遍。以下项目都留给真实设备验收，未预先标记通过。建议先用测试词语，不输入孩子的敏感信息；数据不自动跨模式或跨设备同步。

## 准备

- [ ] Safari 联网打开正确的 /Dangdang/ 地址（大小写一致），等提示「离线资源已准备好」。
- [ ] 分享 → 添加到主屏幕；图标、应用名称和深色启动背景正常。
- [ ] 在系统设置 → 辅助功能 → 朗读内容 → 声音中下载中文增强声音。

## 听写与拼音

- [ ] 输入「春天 花朵，阳光、春天」并换行输入「银行 重复 长大 音乐 好奇」，词数去重正确。
- [ ] 点开始后首词立即朗读，读的是词语，显示带声调拼音。
- [ ] 上一个、重听、显示答案、下一个均可点击；连续快速切题不会叠加多段声音。
- [ ] 静音拨片打开、关闭各测试有无声音，检查媒体音量；无声音时尝试重听并确认系统声音已下载。
- [ ] 调整语速、每词重复次数和间隔，效果正确；拼音开关、切题自动播报开关生效。
- [ ] 手动改拼音，刷新后保留；恢复自动拼音后恢复词典/自动读音。
- [ ] 多音词手动显示与系统实际朗读分别核对，系统发音不受手动拼音控制。

## 核对与掌握状态

- [ ] 全部听写后标对/错，确认后历史、统计正确。
- [ ] 提前结束，尚未经过的词显示未听写；新词成为错过的词。
- [ ] 已掌握词未听写保持已掌握；已未掌握词未听写保持未掌握，错误数与连续次数不变。
- [ ] 三种复习类型连续正确达到设置门槛后成为已掌握；普通听写答对不累计。
- [ ] 已掌握词再次答错后成为未掌握，连续正确次数归零。

## 词单与历史

- [ ] 保存、改名、删除词单；从词单开始听写。
- [ ] 历史列表显示类型、总词数、对错数和时间；详情逐词显示对/错/未听写。
- [ ] 历史再练一次可用；清空历史会二次确认，取消后不丢数据。

## 拍照识别（真实课本 3～5 页）

- [ ] 分别测试单列、多列、带拼音、含页码的课本页；光线均匀、照片尽量端正。
- [ ] 拍照与相册选择均可用；拒绝相机权限时可选择相册或使用系统扫描文本。
- [ ] 裁剪四边范围、识别进度与取消可用。
- [ ] OCR 只保留汉字词，过滤拼音/英文/数字；多列顺序按列再按行，逐词核对错字。
- [ ] 确认页可勾选、编辑、删除、合并和拆分。取消后未入库；确认后才加入输入或保存词单。
- [ ] 使用飞行模式关闭 Wi-Fi 后，从相册选一张照片，OCR 仍能处理（首次缓存必须已完成）。

## 备份与数据持久性

- [ ] 导出 JSON 并保存到「文件」；导入前出现合并预览，取消不改变数据。
- [ ] 连续导入同一份备份两次，不增加重复词语和历史，不覆盖现有手动拼音或掌握度。
- [ ] 导入后词单引用正常；在另一个模式导入备份可恢复记录。
- [ ] 锁屏、切后台、杀后台后重开，已确认保存的词单和历史仍在。
- [ ] 申请持久存储，查看结果；无论授权与否都保留定期备份习惯。

## 离线、更新和布局

- [ ] 等资源就绪后开启飞行模式并关闭 Wi-Fi，彻底关闭应用再打开，仍可进入、从词单练习、核对与保存。
- [ ] 飞行模式朗读有声（系统中文声音已下载）。
- [ ] 重新联网、发布新版本后出现更新提示；听写中不允许刷新，完成后点击刷新能加载新版本，数据保留。
- [ ] iPhone/iPad 横竖屏、底部安全区、长词拼音、输入键盘弹出时布局可用，无横向滚动。
- [ ] 输入框获得焦点不会触发 iOS 自动放大；按钮容易点到。

## 已完成的 Mac 检查（不替代真机）

单元测试、构建、生产子路径、真实本地 Worker 合成样例识别、服务器停止后的 Chrome 刷新/关闭标签重开/词单持久性均已检查。真实设备项目仍按上表逐项验收。
